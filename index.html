    Aula04 - Breakpoints para criação de layouts responsivos

    Veremos nesta aula, como diagramar uma página criando , dimencionando e posicionando regiões de conteúdos para diferentes largura de tela.
    O bootstrap5, possui recursos que facilitam e muito a criação de layout's responsivos.
    São os Breakpoints. O sistema de layout responsivo do bootstrap5, é Mobile first, ou seja, prioriza o desenvolvimento a partir de telas mobile, para somente então, partirmos para o desenvolvimento para telas maiores.
    Veja abaixo, a tabela com os diferentes tipos de ajustes de breakpoints do bootstrap5:




    Veja que o 1º breakpoint é o Extra-pequeno, para telas menores que 576px de largura. Este, é o breakpoint considerado padrão. Para se criar este breakpoint, não é necessário adicionar nenhum infixo.
    Agora, veremos exemplos de classes do bootstrap5 que utilizam infixos de breakpoint.

    1. 1º exemplo: m-5: Esta classe adiciona uma margin de 5 unidades bootstrap em torno do elemento que a contem. Como ela não possui infixo, é uma classe de breakpoint extra-pequeno;
    2. 2º exemplo: p-sm-3: Esta classe adiciona uma margin interna(padding) de 3 unidades ao elemento, quando a resolução estiver na faixa do breakpoint pequeno, ou seja, sm que vêm de "small".Veja que esta classe possui o infixo sm, demonstrando o breakpoint Pequeno;
    3. 3º exemplo: col-lg-2: Esta classe define uma região com duas colunas de largura quando a resolução estiver na faixa do breakpoint grande. Possui o infixo lg que vêm de large;
    4. 4º exemplo: fs-md-6: Esta classe define um tamanho de fonte (font-size) 6, quando a resolução de tela for midium média, ou seja, quando for igual ou superior a 768px de largura.
    5. 5º exemplo: text-xl-end: Esta classe irá alinhar o elemento de texto à direita(end),quando a resolução de tela for extra-large "grande".
      6. ;


    Breakpoints na prática

    No exemplo abaixo, teremos um texto lorem que se ajustará a diferentes larguras de tela conforme configuração dos seus breakpoints.

    1. text-center:Sem infixo, pois o texto se alinha ao centro quando a resolução for padrão, ou seja, menor que 768px de largura;
    2. text-md-start: O texto se alinhará à esquerda quando a resolução de tela for igual ou superior a 768px de largura;
    3. text-xl-end: O texto se alinha à direita quando a largura de tela for igual ou maior que 1200px;

Finalidade: Facilita a navegação ao rolar suavemente a página até a seção de destino, ao invés de "pular" diretamente.     • tabindex="0": O atributo tabindex controla a navegabilidade de um elemento via teclado (usando a tecla Tab, por exemplo). Com o valor 0, a ordem de foco segue o fluxo padrão do documento (ou seja, a sequência natural dos elementos na página). Isso é importante para acessibilidade, permitindo que usuários de teclado e leitores de tela possam navegar até esse conteúdo.

    Aula01 - Seletor :has()

    O seletor :has() é uma pseudo-classe CSS que permite selecionar um elemento pai baseado nos seus elementos filhos. Ele funciona como um "selecionador de pais dinâmico", algo que antes não era possível apenas com CSS puro.

    ✨ Como funciona :has()? Ele seleciona um elemento caso um de seus filhos atenda a uma condição específica.

    📌 Explicação:

    • Ele seleciona a .input-wrapper se o elemento "input" dentro dela estiver focado (:focus);
    • Isso permite que a borda da .input-wrapper mude de cor quando o usuário clicar no input;
    • Sem :has(), precisaríamos de JavaScript para fazer essa relação entre o input e seu elemento pai.

    🚀 Compatibilidade do :has() O :has() é suportado nos navegadores modernos como Chrome e Edge. No entanto, não funciona no Firefox ainda (pelo menos até a versão mais recente). Se precisar garantir compatibilidade total, a solução seria usar JavaScript como fallback.

    🔥 Conclusão

    • O :has() torna o CSS muito mais poderoso, pois permite estilizar um elemento baseado no estado dos seus filhos.
    • Neste caso, ele muda a borda da .input-wrapper quando o input recebe foco, criando uma experiência mais intuitiva.
    • A solução evita JavaScript desnecessário, deixando o código mais leve e elegante.

    Aula01 - História do PHP - Curso em Vídeo

    A Linguagem PHP começou em 1994, quando Rasmus Lerdorf resolveu criar um gerenciador de visitas para o seu site. Sua primeira criação não era uma linguagem, e sim uma ferramenta. Batizada de Personal Home Page, usava comandos simples inspirados da linguagem PERL. A segunda versão da ferramenta já permitia a manipulação de formulários e pequenos livros de visita: o Personal Home Page/ Forms Interpreter, ou PHP/FI. Essa versão ficou bastante popular e começou a se espalhar em 1995.

    Rasmus Lerdorf, nasceu na Groelândia, criou-se na Dinamarka e foi embora para o Canadá onde se profissionalizou em programação na linguagem c.
    Como na época a internet não passava de um envio de um arquivo ao usuário, ele fez a seguinte pergunta: E se eu quizer saber quantas pessoas visitaram o meu site?

    Foi então que criou o PHP nomeando na época como Personal Home Page Tools.No início não era uma linguagem de programação. Era apenas uma interface para saber quantas pessoas estavam visitando o site naquele momento.Utilizou a linguagem Perl para sua construção.
    Na segunda versão, já era possível o usuário preencher dados em um form para interagir com o dono do site. A aplicação mudou então para o nome Personal Home Page Forms Interpreter.

    Após a versão dois do php, Rasmus resolveu abrir o código para toda a comunidade que quizesse colaborar para implementar melhorias.

    Nesta aula, poderemos obter respostas a estas perguntas:

    • Como funciona o PHP?
    • Como transformar meu computador em um servidor?
    • Como funcionam e exemplos de tecnologias Server-side?

    O PHP é uma linguagem de programação server-side, ou seja, o código é processado no servidor e não no cliente. O cliente envia uma requisição ao servidor, que processa o código PHP e devolve a resposta ao cliente. O cliente não tem acesso ao código PHP, apenas à resposta gerada pelo servidor. Isso garante a segurança do código e dos dados do servidor.

    Sabemos então que:

    • HTML é para conteúdo;
    • CSS é para estilo;
    • JavaScript é para interatividade;
    • PHP é para processamento de dados.

    O PHP vêio para completar o nosso conhecimento em Dev Web.

    Como funciona o PHP?


    O PHP é uma linguagem de programação dentro do HTML, e funciona em um servidor (um computador) preparado para interpretá-lo por meio de um programa chamado APACHE.
    O processamento do php gerará um arquivo HTML; O navegador não verá o código php, apenas o HTML gerado pelo servidor.
    Neste arquivo html, veremos apenas tags html ou qualquer outra tecnologia client-side.
    O arquivo html gerado, não será armazenado no servidor, apenas será enviado ao cliente.
    A partir daí, o browser começa a interpretar o arquivo html recebido.


    Como transformar meu computador em um servidor?


    Faremos isso instalando um programa chamado Apache, e uma ferramenta de banco de dados chamada MySQL e um interpretador PHP.


    Como funcionam e exemplos de outras tecnologias Server-side

    Não é só o PHP que possui esta função de processamento server-side. Outras linguagens também o fazem, como o ASP, JSP, Node.js, Ruby on Rails, Python, Java, C#, entre outras.

    Operador de coalescência nula (??)

    Ex: utilizando no operador ternário isset, o operador de coalescência nula...

    $variavel = $_GET[$c1] ?? 0;

    ...ou podemos representá-lo assim também...

    $variavel = $_GET['c1'] ?? 0;

    O null coalescencing operator diz o seguinte:

    Verifica se a expressão à esquerda existe e não é nula!...no caso se foi passado um valor para $c1 e se ele não é nulo!

    Se for true esta afirmação, ou seja, foi passado um valor para $c1 e ele é válido, então o operador ternário o passará para os cálculos posteriores serem executados...

    Se for false esta afirmação, ou seja, não foi passado um valor para $c1 ou foi passado um valor null, então envia para os cálculos o valor default zero(0).

    O que são SUPERGLOBAIS?

    São variáveis pré definidas no php, que são sempre acessíveis, independente do escopo onde estiverem.

    Abaixo veremos uma tabela das superglobais e suas funcionalidades específicas:

    Superglobal Funcionalidade
    $GLOBALS Torna as variáveis acessíveis em qualquer escopo;
    $_SERVER Contêm informações sobre requisições, caminhos etc...
    $_REQUEST
    $_POST
    $_GET
    $_FILES
    $_ENV
    $_COOKIE
    $_SESSION

    $_GLOBALS

    Ex:

    $a = 10;

    $b = 2;

    function soma(){

    $c = $a + $b;

    }

    soma()

    echo $c;

    ...a saída deste script será um erro no php, pois as variáveis $a e $b , estão sendo chamadas dentro do escopo da function soma, apesar de estarem fora dele.

    Para resolvermos isso...

    $a = 10;

    $b = 2;

    function soma(){

    global $a, $b, $c;

    $c = $a + $b;

    }

    soma()

    echo $c;

    ...a saída será... 12

    📌 O que é um PWA?

    PWA (Progressive Web App) é uma tecnologia que permite que aplicações web funcionem como se fossem aplicativos nativos. Com um PWA, seu site pode:

    • Ser instalado na tela inicial do celular/PC;
    • Funcionar offline (total ou parcialmente);
    • Usar notificações push e recursos do dispositivo;
    • Ter performance otimizada e carregamento rápido.

    • Projeto rodando em HTTPS (mesmo que local com localhost);
    • Estrutura de arquivos da aplicação organizada;
    • Acesso ao HTML principal do app;
    • Permissão para adicionar arquivos no root (/) da aplicação.
